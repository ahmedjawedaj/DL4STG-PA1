\section*{Generative AI use}
I used Claude (Anthropic) as a coding and writing assistant, with occasional review passes
from OpenAI Codex, in the way the course policy allows. The design decisions, the
experimental plan and the submitted results are mine. A summary of the prompts, outputs and
edits follows.

\textbf{Prompts.}
\begin{itemize}
  \item Task 1: help completing the three implementation cells in the supplied harness and
        drafting the responses from the numbered notebook Outputs.
  \item Task 2: help writing the Autoformer pipeline (data handling, model, training loop,
        submission writer) and the scripts that run and tabulate the seed and fold
        comparisons described in Section 2.
  \item Writing: first drafts of report paragraphs and tables from the saved results, and a
        check of the final files against the handout requirements.
\end{itemize}

\textbf{Outputs.} Draft code for the items above, draft text and tables, and a list of
checks on the submission files (168 values in order, declared $P$ and $E$ matching the saved
runs).

\textbf{My edits and checks.}
\begin{itemize}
  \item I read and tested the generated code, verified the notebook checks and Outputs, and
        confirmed the numbers in every table against the saved CSV and JSON records.
  \item The expected ordering in Response 1A and the prediction in Response 4(a) are mine
        and were written before the corresponding Outputs were run.
  \item For Task 2, I chose which variants to try, set the acceptance bar for a change
        (better on 20 of 33 winter weeks in both folds), decided what to submit, and
        selected the three members of the final ensemble on the early-stopping set.
  \item I rewrote the drafted text in my own words, cut claims that no saved result
        supported, and added the limits paragraph in Section~\ref{sec:final}.
\end{itemize}

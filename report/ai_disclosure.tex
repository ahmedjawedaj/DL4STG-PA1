\section*{Generative AI use}
I used Claude (Anthropic, with code execution) as the main coding and drafting
assistant, and OpenAI Codex for review, experiments and revisions. The assistance
covered implementation, training scripts, result tables and report text. The examples
below summarise the assignment work; prompts are \textbf{paraphrased}, not verbatim
transcripts, and outputs are summaries of the produced code and saved results.

\begin{enumerate}
  \item \textbf{Task 1 implementation and interpretation.}

        \textbf{Prompt summary:} Read the handout and notebook, complete the three
        cells for attention forecasting, series decomposition and delay aggregation,
        run the full preset, and draft the five responses using the numbered Outputs.

        \textbf{Output:} Implementations of the attention forecaster, endpoint-padded
        moving-average decomposition and vectorised delay aggregation; an executed
        notebook; and draft comparisons of ridge, attention and delay-based models.

        \textbf{Edits/checks:} The notebook checks and full-preset Outputs were
        verified. Responses were edited to explain the measured differences rather
        than repeat the code, identify the population and split, and avoid treating
        attention maps as proof of physical-period recovery.

  \item \textbf{Task 2 forecasting pipeline.}

        \textbf{Prompt summary:} Build a small Autoformer with chronological
        validation, preprocessing, optional-data ablation across multiple seeds,
        plots, and a 168-value forecast with reproducible parameter and epoch counts.

        \textbf{Output:} The \texttt{pa1q2} package for data handling, progressive
        decomposition, Auto-Correlation, training, baselines, comparisons and export;
        three-seed runs with no, past-only and known-horizon external inputs.

        \textbf{Edits/checks:} Scaling and target windows were checked against the
        chronological boundaries. Known-horizon external values were kept because
        the handout permits them and the ablation supports them. Export and tests
        check prediction order, target leakage and epoch accounting.

  \item \textbf{Model size, training and saved variants.}

        \textbf{Prompt summary:} Preserve the current settings, weights and outputs,
        save every variant, and try larger models or longer training to improve
        accuracy before submitting.

        \textbf{Output:} Saved candidate snapshots, a variant log, wider-model
        trials and two- and three-seed ensemble comparisons.

        \textbf{Edits/checks:} The wider trial was stopped when it remained worse
        on early stopping. The compact anchored ensemble became attempt 1 based on
        historical comparisons. Earlier forecasts were retained, and ensemble
        parameters and epochs were summed rather than reported per member.

  \item \textbf{Diagnosing the first result and improving horizon inputs.}

        \textbf{Prompt summary:} Investigate why local RMSE near 69 became 81.56
        on the leaderboard, preserve attempt 1, and test whether the external inputs
        contain signal the Autoformer is not extracting.

        \textbf{Output:} A forecast-reproduction audit, refit experiments, a second
        historical fold, covariate baselines, a nonlinear input embedding and a direct
        covariate head. The latter configuration won 24 of 33 edge weeks and became
        attempt 3.

        \textbf{Edits/checks:} The earlier rank prediction was corrected. Small or
        inconsistent gains were rejected; final members were selected on early
        stopping. The report distinguishes historical from leaderboard scores,
        discloses reused validation blocks and discarded runs, and treats seasonal
        identity and smoothing explanations as hypotheses. The head, anchoring and
        learning-rate changes are reported together rather than attributed to the
        head alone.
\end{enumerate}

Report revisions and checks were also AI-assisted. Tables were checked against saved
CSV/JSON records; the final export contains 168 values with $P=53\,670$, $E=20$.
I remain responsible for the submitted code, results and explanations.
